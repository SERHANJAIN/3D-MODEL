Connect your
generation engine.

FormForge uses an open-source AI model running on your own Apple Silicon Mac. No paid API key or shared demo quota is needed. Keep the local server running while generating.

  1. 01
    Run bash install.command once in Terminal to install the local engine.
  2. 02
    Whenever you want to generate, run bash start.command and keep its Terminal window open.
  3. 03
    Use http://127.0.0.1:8765. First generation downloads several GB of model weights.
